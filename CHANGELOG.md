# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-17

### Added

- Local-first Windows productivity shell: Dashboard, My Day, Tasks, Projects, Calendar, Focus/Pomodoro, Notes, Knowledge Base, Goals, Habits, Snippets, Bookmarks, Environments, Analytics, Daily Plan/Review, Settings
- English (LTR) and Persian (RTL) localization, Dark/Light/System themes
- Global search (`Ctrl+K`) and Quick Add (`Ctrl+Shift+Space`)
- EF Core + SQL Server/LocalDB persistence, demo seed, onboarding
- Import/export, SQL backup helpers, tray notifications
- DPI-aware UI scaling
- Inno Setup installer (`scripts/Build-Installer.ps1` → `DevDesk-Setup.exe`) and per-user portable install script
